# 优化器学习笔记

## SGD

随机梯度下降（SGD）按小批量估计梯度并更新参数。学习率通常需要手工调度。  
本笔记约定：在相同学习率下，SGD 往往比自适应方法更依赖精细调参。

实践备注：当 batch size 从 32 放大到 256 时，可尝试按线性缩放规则同步提高学习率，再结合 warmup 观察损失曲线是否稳定。SGD + Momentum（例如动量系数 0.9）在视觉分类任务中仍常见，但收敛速度通常慢于 Adam 系方法。

## Adam

Adam 同时维护梯度的一阶矩（动量）与二阶矩（能量）估计，并对偏差进行校正。  
笔记要点：Adam 对超参数相对不敏感，适合作为训练初期的默认优化器。

默认超参数备忘（仅作笔记记录，非强制）：β1=0.9，β2=0.999，ε=1e-8。训练早期若出现损失震荡，可优先检查学习率是否过大，而不是立刻换成 SGD。

## AdamW

AdamW 将权重衰减（weight decay）与梯度更新解耦，而不是把 L2 惩罚直接加进损失函数再交给 Adam。  
本笔记中的对比结论：**在相同任务上，AdamW 的权重衰减实现与 Adam+L2 并不等价**；若笔记未给出具体准确率数字，不得编造。

调参建议：Transformer 类模型常见 weight decay 取值区间为 0.01–0.1；对 bias 与 LayerNorm 参数，许多实现会关闭权重衰减。本笔记未给出 ImageNet / GLUE 等基准上的具体 Top-1 或分数，禁止用外部常识补全数字。

## 学习率调度备忘

常见调度包括：StepLR、CosineAnnealing、Warmup + Cosine。  
笔记约定：若未写明具体 warmup 步数，回答时不得臆造「必须 warmup 2000 step」之类硬性数字。  
经验写法：先用 Adam/AdamW 快速验证可训练性，再视任务决定是否切回经充分调参的 SGD。

## 梯度裁剪与稳定性

当序列模型出现梯度爆炸迹象（loss 突然 NaN 或尖刺）时，可启用全局范数梯度裁剪，例如 `max_norm=1.0`。  
裁剪阈值属于工程经验，本笔记不宣称某一阈值在所有任务上最优。
